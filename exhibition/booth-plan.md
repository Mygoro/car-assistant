# car-assistant 부스 운영 매뉴얼

전시일 2026-06-02(화), 약 6시간 · 1인용 테이블 + 노트북 1대 + 콘센트 1개
짝 문서: `roadmap.md`(전체 설계), `demo-script.md`(시연 대본)

전제: 봇은 집 GPU 데스크탑에서 원격 구동. 부스 노트북은 Discord **클라이언트**(음성 채널 접속,
출력 전용)일 뿐이다. 콘센트·Wi-Fi는 사용 가능으로 가정한다.

---

## 1. 부스 물리 배치

```
        [ 포스터 — 이젤 또는 벽 ]
   ┌─────────────────────────────────┐
   │  안내카드      노트북       파워드 │
   │  스탠드   ┌───────────┐   스피커  │
   │   ▭      │  데모영상   │    ◙     │
   │          │  /채팅로그  │          │
   │   폰      └───────────┘  동의문   │
   │  거치대                   ▭       │
   └─────────────────────────────────┘
        [ 의자 — 본인 ]   [ 방문자 동선 ]
```

- **노트북**: 중앙. 평소 데모 영상 루프 재생, 라이브 시 Discord 채팅 로그(트랜스크립트) 표시.
- **파워드 스피커**: 노트북에 유선 연결. 봇 음성 출력 — 관람객이 들어야 함.
- **폰**: 거치대에 세워 둠. Discord 모바일 앱으로 음성 채널 접속(입력 전용, Krisp 노이즈 억제).
- **안내 카드 스탠드**: 방문자용 예시 질문 카드.
- **동의문**: 테이블 앞쪽, 방문자가 읽을 수 있게.

## 6. 방문자 응대 흐름

1. 인사 + 30초 엘리베이터 피치 (demo-script.md 참조)
2. 동의문 안내 — "음성은 저장하지 않습니다" 구두 1줄
3. 시연 방식 선택:
   - 관람만 원함 → 본인 시연(메인 안)
   - 직접 해보고 싶음 → 헤드셋 전달, "아무거나 물어보세요" 안내 (머뭇거리면 안내 카드)
4. 시연 후 질문 응대
5. 헤드셋 사용 시 일회용 커버 교체

## 8. 인쇄물 최종본

### 8-A. 개인정보 동의 안내문

> **음성 데이터 안내**
>
> 이 데모는 여러분의 음성을 텍스트로 변환해 AI 응답을 생성합니다.
> 음성과 텍스트는 **저장하지 않으며** 응답 직후 폐기됩니다.
> 처리 과정에서 외부 AI 서비스(Anthropic, ElevenLabs)로 텍스트가 전송됩니다.
> 시연을 원치 않으시면 관람만 하셔도 됩니다.
> 진행하시면 위 내용에 동의하신 것으로 간주합니다.

[확인 필요: 외부 API 전송 명시 문구가 학과 가이드라인에 부합하는지]

### 8-B. 방문자 안내 카드

> **OTTO에게 아무거나 물어보세요**
> 헤드셋을 착용하고, 받아쓰기가 소음에 약하니 또박또박 말씀해 주세요.
>
> 뭘 물어야 할지 모르겠다면 이렇게 시작해 보세요:
> 1. "hey OTTO, 오늘 무슨 요일이야?"
> 2. "hey OTTO, 간단한 농담 하나 해줘"
> 3. "hey OTTO, 연세대학교는 어떤 학교야?"
>
> ※ 위 예시는 마중물일 뿐, OTTO는 정해진 질문만 답하지 않습니다.
