## 0. 이번 판이 기존 plan을 갈아엎은 이유

기존 booth-plan은 "공용 스피커 + 헤드셋 + 본인 아이패드 + **본인 시연** 중심"이었다. 사용자 결정으로 모델이 **순수 QR 셀프서비스**(방문자 본인 폰으로 듣고 말함)로 바뀌면서, **공용 스피커·입력폰 거치대·본인 시연 스테이션이 전부 불필요**해졌다. 대신 (1) 소음 홀 대비 **대여 이어폰**, (2) 흡인용 **라이브 대화 미러**, (3) **개관 시간만 공개**가 새 축이다. 또 무인 시간에도 방문자가 직접 쓰므로 **세션 격리·오너게이트·목업 배선이 "있으면 좋은 것"이 아니라 "없으면 깨지는 것"**이 됐다(§4 개발 트래커).

## 1. 접속 흐름 (방문자 동선)

```
방문자 본인 폰
  │ ① QR 스캔 → 디스코드 초대링크
  ▼
디스코드 서버 입장 → #시작 채널 자동 안내
  │ ② 목업 공지 읽음("당신은 가상 학생 OOO. 이번 주 상황은…") + 예시 카드
  ▼
음성채널 입장  (User Limit = 1 · 봇은 limit 제외 → 봇+1명만)
  │ ③ 부스 비치 대여 이어폰 착용(일회용 커버)
  ▼
"크랭크 오토, [질문]"  ──음성──▶  봇 응답(이어폰으로 들음)
  │ ④ 대화 종료/이탈 시 다음 사람 입장 가능
  ▼
[부스 노트북] 텍스트 채널을 풀스크린 미러 → 지나가는 사람이 Q&A 실시간 관전
```

- **동시 통화자는 항상 1명**(음성채널 limit 1). 2번째는 대기 → 자연스러운 줄서기.
- **폐관 후**: 음성채널 잠금/봇 음소거(또는 초대링크 비활성)로 무인 시간 노출 차단.

## 2. 부스 물리 배치

```
        [ 포스터 A3 — 이젤/벽 ]   [ 대형 QR 사이니지 ]  ← 히어로 요소
   ┌─────────────────────────────────────────────┐
   │                ┌───────────────┐             │
   │   대여 이어폰    │  부스 노트북     │   동의문    │
   │   + 커버함      │  라이브 대화미러 │    ▭       │
   │     ▭         │ (idle 시 영상)  │            │
   │               └───────────────┘             │
   │   안내카드(QR 사용법 3줄)        멀티탭        │
   └─────────────────────────────────────────────┘
        [ 의자 — 당번 시 ]
```

- **대형 QR**: 부스의 주역. 디스코드 초대링크 인코딩. 눈높이·고대비·"폰으로 찍으세요" 한 줄.
- **부스 노트북**: 디스코드 **텍스트 채널 풀스크린**(STT 질문 + 봇 답변 실시간 미러). **음성채널엔 접속 안 함**(접속하면 비봇 유저 2명이 되어 오너게이트·limit 로직이 깨짐 — §4-1). 방문자 없을 땐 데모영상 루프.
- **대여 이어폰 1~2개**(마이크 포함) + **일회용 커버함** + 사용 후 수거함. 소음 홀 STT 양방향 개선.
- **안내카드**: QR 못 찍는 사람용 3줄 사용법(아래 §9-C).
- **동의문**: 테이블 앞, 음성 미저장 안내.

| 인쇄물 | 동의문·QR 사용법 카드 | §9 |

| # | 항목 | 왜 필요 | 출처/난이도 |

## 5. 디스코드 서버 셋업 체크리스트

- [ ] **초대링크 생성** → 만료/사용횟수 정책 결정(전시 기간 한정 권장) → QR 인코딩·출력
- [ ] **#시작 채널**: 시나리오 라이터 산출물 게시 — (a) 목업 공지/페르소나 브리핑, (b) 되는 발화 예시 카드, (c) 사용법 3줄. **읽기 전용**
- [ ] **음성채널 User Limit = 1** (봇은 limit 제외 확인)
- [ ] **미러용 텍스트 채널**: 봇 transcript 출력 채널. 부스 노트북이 이 채널만 풀스크린
- [ ] **권한 잠금**: @everyone 메시지 전송 제한(트롤 차단), #시작·미러 채널 읽기 전용, 음성채널만 입장 허용
- [ ] **폐관 후 비활성**: 음성채널 잠금 또는 봇 음소거(개관 시간만 공개 §6)
- [ ] **전시 종료 후**: 초대링크 폐기·서버 보관/삭제

## 7. 트러블 대응표 (무인 셀프서비스 전제)

| 증상 | 1차 | 2차 |
|------|-----|-----|
| wake 미감지 | 안내카드 "크랭크 오토,…" 또박또박 | (D7 적용 시) wake 생략 모드 |
| STT 인식 실패(소음) | 대여 이어폰 마이크 사용 유도 · 천천히 | 미러에 안내 문구 고정 |
| 봇 무응답/크래시(SSL 등) | watchdog 자동재시작 대기 | 원격 python kill 후 재기동(H6) · 미러를 영상루프로 |
| rate limit 429 | limit 1+개관시간이라 빈도 낮음 | Tier2 $40 결제수단 상시 준비(M1) |
| 데스크탑/Wi-Fi 두절 | 폰 핫스팟 전환 | 미러 노트북 **데모영상 로컬 루프**로 후퇴 |
| 디스코드 가입/마이크 권한 막힘 | 안내카드대로 권한 허용 | 당번이 본인 폰으로 대신 시연 |
| 장소 환각 의심 답변 | 시연 동선을 검증된 송도 장소로 한정(시나리오) | 해당 발화 카드에서 제외 |

**원칙**: 어떤 장애든 **미러 노트북을 데모영상 무한루프로** 10초 내 후퇴(로컬 저장, 인터넷 불요). "폴백은 실패가 아니라 설계된 경로."
